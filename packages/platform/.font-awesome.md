# Font Awesome Configuration

## Integration

- **Method:** Official React components via `@fortawesome/react-fontawesome`, with individual imports from the npm Kit package.
- **Kit ID:** b228b21a21
- **Kit package:** `@awesome.me/kit-b228b21a21`, version 1.0.2 at setup.
- **Families in use:** Slab.

## Defaults

- **Family:** slab
- **Style:** regular

## Import Pattern

```tsx
import { faBox } from "@awesome.me/kit-b228b21a21/icons/slab/regular"
import { FontAwesomeIcon } from "@fortawesome/react-fontawesome"

<FontAwesomeIcon icon={faBox} aria-hidden="true" />
```

## Conventions

App icons use the Slab Regular box; commit metadata uses the Slab Regular code icon. Import individual icons directly from the kit; do not register whole families. The root imports SVG core CSS and disables automatic CSS injection for server rendering. Keep package credentials in the developer's npm configuration, outside the repository.
