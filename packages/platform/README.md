# Platform

From the repository root, start local development with configuration supplied by Doppler:

```sh
doppler run -p platform -c dev -- pnpm dev:watch
```

See [DEVELOPING.md](../../DEVELOPING.md#platform-development) for configuration, prerequisites, built startup, and database commands, [shared-secret verification](../../DEVELOPING.md#shared-secret-management-verification) for the local and production vault setup, and [ARCHITECTURE.md](../../ARCHITECTURE.md) for platform ownership.
