# Auth-forwarding Worker

Follow ARCHITECTURE.md's [domain model](../../ARCHITECTURE.md#domain-model) and viewer authentication boundary. Use Hono for routes and cookies and Better Auth's native one-time-token endpoint for the server-side exchange at `auth.contextlayer.xyz`. Do not add a session database, OAuth client, or signing secret. Keep configuration in `env.ts`.

Validate the return URL as HTTPS on a single slate subdomain of `CTX_SLATES_DOMAIN`, excluding `auth`, ports, and URL credentials. Keep the random state and return URL in the host-only HttpOnly `__Host-ctx_handoff` cookie; validate the callback state against it before exchanging the one-time token. Store the returned Better Auth session token in the domain-wide HttpOnly `ctx-viewer-auth` cookie with that session's expiry. Clear the handoff cookie after the exchange and keep callback responses uncached with no referrer. Leave viewer verification and organization authorization to platform's existing web boundary, and never pass session credentials to authored Workers.
