---
title: "Secrets"
description: "Named values, such as API keys, that belong to an Owner and that slates declare by name and mode."
---

A secret is a named value, such as an API key, that a slate's consumers declare by name. The declaration holds only the name and a mode. The value belongs to an Owner and is stored by ContextLayer, never in `slate.json` or in authored code.

## Declare a secret

Secrets are declared under `secrets`, keyed by name, with a mode. A name uses uppercase letters, digits and underscores, and cannot start with a digit. For example, an agent selects its hosted model with this entry in `agents/<name>/slate.json`:

```json
{
  "connections": {},
  "secrets": {
    "ANTHROPIC_MODEL": {
      "mode": "owner"
    }
  }
}
```

Hosted agents read their model settings from declared secrets: `ANTHROPIC_MODEL` selects the model, and `ANTHROPIC_API_KEY` or `CLAUDE_CODE_OAUTH_TOKEN` supplies provider access.

## Where the value comes from

A declared secret refers to the shared secret of the same name that belongs to the Owner its mode selects. A shared secret belongs to its personal or organization Owner, not to a slate, so every slate that selects the same Owner and name uses the same value.

```json agents/digest/slate.json
{
  "connections": {},
  "secrets": {
    "ANTHROPIC_MODEL": { "mode": "owner" },
    "ANTHROPIC_API_KEY": { "mode": "viewer" }
  }
}
```

- **Owner mode.** The value is the slate Owner's shared secret. Save it with the CLI's `secrets` command, for yourself or for an organization you belong to; run `npx @usecontextlayer/cli secrets --help` for its operations. The same operations are in the API reference's Shared secrets group: [Set a named secret belonging to an Owner](https://docs.usecontextlayer.com/api-reference/shared-secrets/set-a-named-secret-belonging-to-an-owner) and [Delete a named secret belonging to an Owner](https://docs.usecontextlayer.com/api-reference/shared-secrets/delete-a-named-secret-belonging-to-an-owner).
- **Viewer mode.** Each viewer supplies their own value, saved as their personal shared secret. In a hosted slate, the chrome, the ContextLayer header at the top of the slate, lists the viewer-mode secrets and lets each viewer save a value. It shows whether a value is saved, never the value itself. Until a viewer has supplied it, their viewer-mode tool calls and queries throw a `secret-required` response that names the secret, and the starter's root error boundary asks them to save it.

The operation [Set a declared secret for its selected Owner](https://docs.usecontextlayer.com/api-reference/slate-resources/set-a-declared-secret-for-its-selected-owner) saves a value for whichever Owner a slate's declaration selects.

## Local values

In a checkout, a secret's value comes from the environment variable with the declared name, whatever the mode. Values stored in ContextLayer are never used locally. Restart `pnpm dev` after changing a value.

## Values stay in trusted execution

No operation returns a stored value: saving or deleting a secret returns only its Owner and name. ContextLayer loads a value only inside its own execution, where the value is used.
