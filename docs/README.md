# ContextLayer docs

This directory is the ContextLayer documentation site, published by Mintlify at [docs.usecontextlayer.com](https://docs.usecontextlayer.com) on every push to `main`. Pages are MDX files; `docs.json` holds the site settings and navigation.

Preview locally from this directory with `npx mint@latest dev`, and check it with `npx mint@latest validate`.
