---
title: "Quickstart"
description: "Create a slate, run it locally, push it, and open the deployed slate."
---

This page assumes you have finished [Installation](/installation): the prerequisites are in place and `login` was approved.

Three steps here need a person rather than a coding agent: supplying their Git name and email, choosing who owns the slate, and signing in to open the deployed slate. Each is called out where it comes up.

<Steps>
  <Step title="Create the slate">
    ```sh
    npx @usecontextlayer/cli init my-slate
    ```

    `init` creates a private slate and writes a starter app (React Router, Tailwind, and shadcn) into the directory you name. It installs the dependencies, commits the starter on `main`, and sets the checkout's Git remote to the slate's repository. It prints the slate's dashboard link and its hosted URL. The hosted URL works only after the first deployment.

    The directory name is only local. ContextLayer names the slate itself, and that name is the first label of the hosted URL.

    By default the slate's Owner is you, a personal Owner. It can instead belong to an organization you are a member of; `npx @usecontextlayer/cli init --help` shows how. Who owns the slate is the person's decision.

    If Git has no author identity, `init` stops and prints Git's configuration commands. The name and email are the person's own. Set them, then run `init` again.
  </Step>
  <Step title="Run it locally">
    ```sh
    cd my-slate
    pnpm dev
    ```

    `pnpm dev` prints a local URL. Open it to see the first screen, which reads and writes the starter's `notes` database. That screen is `app/routes/home.tsx`; edit it to build your own.

    The checkout's `AGENTS.md` and `README.md` are the authoring instructions. `AGENTS.md` is written for coding agents, and the checkout's `CLAUDE.md` imports it. `README.md` covers local development, connected services, databases, and deployment.
  </Step>
  <Step title="Deploy">
    ```sh
    git add .
    git commit
    git push -u origin main
    ```

    Pushing `main` starts the build and deployment. ContextLayer builds the pushed commit, applies its database migrations, and deploys it. `init` already committed the starter, so if you have changed nothing, `git push -u origin main` on its own deploys it.
  </Step>
  <Step title="Open the deployed slate">
    Open the hosted URL that `init` printed. The slate is private, so you sign in to ContextLayer to open it. This happens in the person's browser; a coding agent hands them the URL.
  </Step>
</Steps>
