ContextLayer is a platform for building slates: software shaped around the way people work. A slate is one Git repository that holds an app, its agents and the resources they use, and a Git push deploys it. You build it with ordinary code, React Router, TypeScript and SQL, in your editor and with your coding agent.

## What is in a slate

A slate has an app, agents and MCPs, and the resources they declare.

- The **app** is the interactive part: a React Router app that people open in the browser.
- **Agents** are named sets of standing instructions that run as hosted jobs, on demand or on a schedule.
- **MCPs** expose a slate's tools and views to MCP clients.
- **Resources** are what those three consume: **connections** to services such as Gmail or Slack, **databases**, and **secrets**. Each consumer declares the resources it needs in its `slate.json`.

An **account** is a connected account, for example your Gmail, held by its Owner independently of any slate. An **assignment** maps a connection a slate declares to an account that satisfies it.

## Owners and viewers

An **Owner** is the personal or organization identity that owns a slate, an account or a shared secret. **Viewers** are the people who open a slate. Every declared resource has a mode: in **owner mode** the slate's Owner supplies it and everyone shares it; in **viewer mode** each viewer supplies their own. That is how one slate can use the Owner's shared database and each viewer's own inbox at the same time.

## Working with a coding agent

The docs are written for people and for the agents that work with them. Every page is available as Markdown by adding `.md` to its URL, `/llms.txt` lists them all, and `npx skills add https://docs.usecontextlayer.com` installs ContextLayer's skill into your agent.
