---
title: "Installation"
description: "Check the prerequisites and sign in to ContextLayer from the command line."
---

Set up the required tools, check that the CLI runs, and sign in to the ContextLayer account you will use to create and manage slates. Run the CLI with `npx`; you do not need a global installation.

## Prerequisites

- Node.js 22.22.0 or newer, to run the CLI.
- [pnpm](https://pnpm.io/installation), to install a slate's dependencies.
- Git, configured with your author name and email, to version and push the slate's code.

Your Git author identity appears on commits and is separate from your ContextLayer login. If a coding agent is setting up Git for you, give it the name and email you want to use; it should not invent an identity.

## Run the CLI

```sh
npx @usecontextlayer/cli --help
```

The help output lists the available commands. Add `--help` to a command to see its arguments and options.

## Sign in

Signing in requires a person to approve the CLI in a browser. The account that approves the request becomes the CLI's identity.

<Steps>
  <Step title="Start sign-in in the terminal">
    ```sh
    npx @usecontextlayer/cli login
    ```

    The command prints a URL and a code, then waits for approval. Leave it running while you complete the browser step.
  </Step>
  <Step title="Approve with the account you want the CLI to use">
    Open the printed URL in your browser. Sign in to ContextLayer, or create an account, then check that the browser shows the same code as the terminal. Approve the request.

    If a coding agent started the command, it should give you the URL and code and wait for you to approve. This step determines whose account the agent will act through.
  </Step>
  <Step title="Wait for the terminal to confirm sign-in">
    The CLI prints `Signed in to ContextLayer.`, then configures Git authentication and prints `Git credentials configured for ContextLayer.`

    The first message confirms the CLI's login. The second confirms that Git can use those credentials when you push a slate to ContextLayer.
  </Step>
</Steps>

You are ready to create your first slate. Continue with the [Quickstart](/quickstart), or [use the platform API from the CLI](/how-to/use-the-platform-api) to discover and invoke platform operations with this login.
