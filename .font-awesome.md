# Font Awesome Configuration

## Integration

- **Method:** Official React components via `@fortawesome/react-fontawesome`, with individual imports from the npm Kit package.
- **Kit ID:** e146ba5a27
- **Kit package:** `@awesome.me/kit-e146ba5a27`, using the `latest` version selector shared with web.
- **Families in use:** Slab.

## Defaults

- **Family:** slab
- **Style:** regular

## Import Pattern

```tsx
import { faBox } from "@awesome.me/kit-e146ba5a27/icons/slab/regular"
import { FontAwesomeIcon } from "@fortawesome/react-fontawesome"

<FontAwesomeIcon icon={faBox} aria-hidden="true" />
```

## Conventions

Slate icons use the Slab Regular box; commit metadata uses the Slab Regular code icon. Import individual icons directly from the kit; do not register whole families. The platform document root imports SVG core CSS and disables automatic CSS injection for server rendering. Keep package credentials in the developer's npm configuration, outside the repository.
